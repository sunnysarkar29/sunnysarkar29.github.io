# Source figure crop audit

Every `question-*.webp` figure included in the assessment pages has been regenerated directly from the uploaded source PDF at 3.1 pixels per PDF point. Crops exclude unrelated page headings, other questions, and surrounding answer instructions. Each crop includes the full relevant diagram or plot, its axes and tick labels where applicable. Original question wording and equation text are typeset in the HTML above the solutions; graphical crops are intentionally **figure-only** unless the source was itself a textbook question photographed into the PDF (Homework 6 Problems 1 and 2).

Each source image is clickable and opens as a full-resolution file (offline). The JSON file alongside this README records original PDF, page number and crop rectangle in PDF points for every image. Figures are assigned to the matching question section, and no PDF is needed to use the website.
