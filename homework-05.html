Problem 1(a) — Adding a real zero to a resonant second-order plant

EXACT QUESTION TEXT FROM SUPPLIED PDF · Homework 5

For this problem, we’ll explore time and frequency domain relationships.

1. For the following transfer function

\[G(s)=\frac{(s+a)}{a}\cdot\frac{25}{s^2+2\cdot0.3\cdot5s+25}.\]

(a) Use MATLAB to make Bode plots for \(a=1,10,100\) superimposed upon each other (use the "hold on" command after using the Bode command). Also plot the step responses superimposed upon each other. Make sure your axes are labeled and your figure(s) have title(s).

(b) Explain the step response using using only the information in the frequency response (Bode plot) plots. Use the ideas from class such as bandwidth, and peak gain response to explain the results.

Before revealing the reasoning

For each a, write pole/zero break frequencies and compare frequency-response peaks with step overshoot and rise behavior.

Worked solution — answered by question part

Jump to: (a)(b)

Part (a) — Make overlaid Bode and step-response plots for a = 1, 10, 100

The assigned family is

\[G_z(s;a)=\frac{s+a}{a}\cdot\frac{25}{s^2+3s+25},\qquad a\in\{1,10,100\}.\]

The second-order poles remain fixed at \(-1.5\pm j4.770\) (\(\zeta=0.3,\omega_n=5\)). The new zero is at \(-a\), with a DC-normalized factor \(1+s/a\). Its magnitude and phase are

\[\left|1+\frac{j\omega}{a}\right|=\sqrt{1+(\omega/a)^2},\quad\arg(1+j\omega/a)=\tan^{-1}(\omega/a).\]
s=tf('s'); aVals=[1 10 100];
figure; hold on;
for a=aVals
  G=((s+a)/a)*(25/(s^2+3*s+25));
  bode(G);
end
grid on; legend('a=1','a=10','a=100');
figure; hold on;
for a=aVals
  G=((s+a)/a)*(25/(s^2+3*s+25));
  step(G);
end
grid on; legend('a=1','a=10','a=100'); xlabel('Time (s)'); ylabel('Output');

In MATLAB, bode often handles multiple systems more reliably in a single call; the loop illustrates the repeated-system construction. Include titles and labels when saving the figures.

Part (b) — Explain the time response from the frequency-response changes

For \(a=100\), the zero is far beyond the \(5\)-rad/s dynamics; the system behaves nearly like the original underdamped second order. At \(a=10\), the zero modestly emphasizes higher frequencies and sharpens the leading edge. At \(a=1\), the zero acts well before resonance and significantly increases mid/high-frequency gain; the step rises faster and can overshoot more. A left-half-plane zero need not make the closed-loop step more damped: it can make the transient more aggressive by altering residues and initial slope.

The final values are all \(G_z(0)=1\), so differences are purely transient, not DC tracking changes.

Self-check: Does a move toward right-half-plane zeros suggest more overshoot?

Problem 1(b) — Adding a real pole instead

EXACT QUESTION TEXT FROM SUPPLIED PDF · Homework 5

2. For the following transfer function

\[G(s)=\frac{a}{(s+a)}\cdot\frac{25}{s^2+2\cdot0.3\cdot5s+25}.\]

(a) Use MATLAB to make Bode plots for \(a=1,10,100\) superimposed upon each other (use the "hold on" command after using the Bode command). Also plot the step responses superimposed upon each other. Make sure your axes are labeled and your figure(s) have title(s).

(b) Explain the step response using using only the information in the frequency response (Bode plot) plots. Use the ideas from class such as bandwidth, and peak gain response to explain the results.

Before revealing the reasoning

The added low-frequency pole can dominate the long transient: compare the slow pole with the second-order pair.

Worked solution — answered by question part

Jump to: (a)(b)

Part (a) — Make overlaid Bode and step-response plots for a = 1, 10, 100

The second family is

\[G_p(s;a)=\frac{a}{s+a}\cdot\frac{25}{s^2+3s+25}.\]
s=tf('s'); aVals=[1 10 100];
figure; hold on;
for a=aVals
  G=(a/(s+a))*(25/(s^2+3*s+25));
  bode(G);
end
grid on; legend('a=1','a=10','a=100');
figure; hold on;
for a=aVals
  G=(a/(s+a))*(25/(s^2+3*s+25));
  step(G);
end
grid on; legend('a=1','a=10','a=100'); xlabel('Time (s)'); ylabel('Output');

In MATLAB, bode often handles multiple systems more reliably in a single call; the loop illustrates the repeated-system construction. Include titles and labels when saving the figures.

Part (b) — Explain the time response from the frequency-response changes

The added pole factor has magnitude \(1/\sqrt{1+(\omega/a)^2}\) and phase \(-\tan^{-1}(\omega/a)\). At \(a=100\), it has little effect around \(\omega_n=5\); at \(a=10\), it adds noticeable rolloff and phase lag; at \(a=1\), it suppresses much of the resonant bandwidth and slows the initial response substantially. The DC gain remains 1.

The comparison teaches two distinct facts: (1) a smaller bandwidth usually corresponds to a slower rise when other features remain similar; (2) resonance and overshoot are influenced by poles, zeros, and excitation residues, not bandwidth alone. Compare the phase as well as the magnitude when making causal claims.

Self-check: Does the slowest pole dominate later times?
