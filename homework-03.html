Problem 4 — Reduce a ninth-order aircraft model responsibly

EXACT QUESTION TEXT FROM SUPPLIED PDF · Homework 3

In this problem, you’re going to discard negligible poles and zeros of the dehaviland Beaver elevator to pitch-rate transfer function identified in homework 2 . As a starting point, you’ll need the 9th order transfer function from elevator to pitch rate as used in homework 2 problem 1.

  1. Use the MATLAB function pzmap to observe the location of the poles and zeros. Include a plot of pzmap. Use the guidelines given in class and discard poles and zeros that have a negligible affect on the step response. Justify any pole or zero that you choose to omit. Note that there are many ways to construct a new transfer function, or to neglect/discard poles and zeros, in a current transfer function. One such method is to create a new transfer function in the pole-zero-gain form mentioned in lecture 2. If you choose this method, you’ll have to match the DC gain and sign of the newly created, lower order, transfer function with the original 9th order transfer function.
  2. Write out, or include a screen shot, of the final form of the elevator to pitch rate transfer function.
  3. Plot, in the same figure, the step response of the 9th order transfer function and your reduced order transfer function. Make sure to include a legend on the plot and have your axes and figure labeled.
Before revealing the reasoning

Work from the ninth-order poles/zeros only if the actual aircraft model is available. Preserve DC gain when proposing a reduced model.

Worked solution — answered by question part

Jump to: (1)(2)(3)

Part (1) — Choose negligible poles and zeros and justify model reduction

The nine-pole elevator-to-pitch-rate model comes from Homework 2's separately supplied Simulink aircraft example; its coefficients are absent from the files. The following is a rigorous workflow, not a made-up aircraft result.

  1. Use pzmap to inspect all poles and zeros, recording approximate cancellation pairs and pole real parts.
  2. Identify poles with large negative real parts compared with the bandwidth of interest. A fast pole \(-a\) contributes a step transient proportional to \(e^{-at}\); its time scale is \(1/a\). A fast pole alone is not automatically negligible when a zero creates a large residue.
  3. Retain dominant poles and important zeros, then construct a reduced-order pole-zero-gain model.
  4. Match the signed DC gain: for a candidate \(G_r\), set its multiplier \(k\) so \(G_r(0)=G(0)\), provided \(G(0)\) exists.
  5. Compare the two step responses in the same plot and quantify maximum error, settling, overshoot, and steady-state gain.

Part (2) — State the reduced transfer function

For example, if an illustrative plant is \(G(s)=10(s+20)/[(s+2)(s+18)(s+25)]\), a low-frequency approximation can replace the fast factor \((s+20)/[(s+18)(s+25)]\) by its value at zero, giving \(G_r(s)=\frac{10\cdot20}{18\cdot25}\frac1{s+2}\). This is an illustration, not the missing Beaver model.

Data limitation: The actual numerical reduced transfer function cannot be stated without the ninth-order Simulink-derived original; the displayed lower-order model is only an illustrative example, not the aircraft solution.

Problem 5 — Resonance, noise, reference tracking, and prefilter design

EXACT QUESTION TEXT FROM SUPPLIED PDF · Homework 3

Fret not, each of the steps below should take approximately 5 minutes.

Consider the following closed-loop reference-to-output transfer function

\[T(s)=\frac{100}{s^2+4s+100}.\]
  1. Create a Bode plot of the reference-to-output transfer function in MATLAB.
  2. Will sensor noise be magnified across any frequency range? For the purposes of this assignment, consider a magnification to be anything greater than 1 dB. (Hint: See the solution to homework 2 problem 5).
  3. Will a reference signal be magnified across any frequency range?
  4. Design a prefilter to achieve an overall closed-loop response that matches \(T_{ideal}=\frac{100}{s^2+16s+100}\) exactly. A prefilter, in this case, is a transfer function that sits before the closed-loop transfer function and "shapes" the reference signal as needed.
  5. Plot the step response of the original system and the system with a prefilter.
  6. With the prefilter involved, how has the transfer function from noise to output changed?
Before revealing the reasoning

Find the resonance peak of T; solve F T=Tideal algebraically, then re-evaluate the noise path without changing the feedback loop.

Worked solution — answered by question part

Jump to: (1)(2)(3)(4)(5)(6)

Part (1) — Create the Bode plot of T(s)

The given closed-loop transfer function is

\[T(s)=\frac{100}{s^2+4s+100},\quad\omega_n=10,\quad\zeta=\frac4{20}=0.2.\]
sys = tf(100,[1 4 100]);
figure; bode(sys); grid on; title('Reference-to-output response');

Part (2) — Determine whether sensor noise is magnified

It has unit DC gain. For \(\zeta<1/\sqrt2\), the resonance frequency is \(\omega_r=\omega_n\sqrt{1-2\zeta^2}=\sqrt{92}\approx9.59\) rad/s, and

\[M_r=\frac1{2\zeta\sqrt{1-\zeta^2}}\approx2.552\quad(8.14\text{ dB}).\]

Reference: \(Y/R=T\), so the reference is magnified near \(\omega_r\). Sensor noise: for the standard unity negative-feedback loop the sensor-noise path is \(Y/N=-T\), giving the same magnitude peaking. Both exceed the assignment's 1-dB threshold. The claim depends on the standard feedback location of noise.

Answer: Yes. For the standard unity-feedback noise injection, \(Y/N=-T\), and the peak near 9.59 rad/s is about 8.14 dB, exceeding 1 dB.

Part (3) — Determine whether the reference is magnified

Answer: Yes. The reference-to-output response is \(Y/R=T\), so it has the same approximately 8.14 dB resonance above unity.

Part (4) — Design the exact ideal-response prefilter

To make the reference response equal to

\[T_{\rm ideal}(s)=\frac{100}{s^2+16s+100},\]

insert a prefilter \(F\) satisfying \(FT=T_{\rm ideal}\). Hence

\[\boxed{F(s)=\frac{T_{\rm ideal}(s)}{T(s)}=\frac{s^2+4s+100}{s^2+16s+100}.}\]

Part (5) — Compare the step responses before and after filtering

This proper stable prefilter cancels the modeled poles/zeros algebraically in the reference channel, yielding \(Y/R=T_{\rm ideal}\) with damping ratio \(0.8\). It has unit DC gain, so tracking at steady state is unchanged. But a prefilter does not appear in the sensor-feedback noise path, so \(Y/N=-T\) remains exactly the same (assuming unchanged inner loop). That is the key conceptual distinction tested in the last subquestion.

F = tf([1 4 100],[1 16 100]);
figure; step(sys,F*sys); legend('Original T','Prefiltered F*T'); grid on;

The filtered response has the desired more heavily damped denominator; numerical plots should use both models on the same axes.

Part (6) — State how the noise-to-output transfer changes

Answer: It does not change in the standard feedback arrangement: \(Y/N=-T(s)\) remains the same, because the prefilter is only in the reference path and not in the noise-feedback loop.

Additional reasoning, cautions, and checks

Model caution. Exact cancellation in an input prefilter assumes the estimated closed-loop model is exact. Errors leave residual transients, so do not present the prefilter as a robustness improvement.

Self-check: Does F*T equal Tideal? Does reference filtering leave the sensor-noise path unchanged?
